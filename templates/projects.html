SmartLabTwinAI

An AI-Powered Digital Twin for Intelligent Laboratory Monitoring, Predictive Maintenance, and Smart Energy Management

GitHub Repository

SmartLabTwinAI represents Annareddy Naveen Kumar Reddy's flagship engineering innovation: an end-to-end cyber-physical IoT digital twin engineered for academic and industrial research laboratories. By deploying calibrated sensors interfaced with ESP32 microcontrollers, the platform continuously streams temperature, humidity, voltage, and current parameters. An embedded and cloud-based machine learning anomaly classifier detects electrical surges, forecasts component degradation, and dynamically sheds non-critical power loads for smart energy efficiency.

Core Engineering Capabilities:

  • ESP32 Microcontroller Interfacing: Real-time ADC sampling of ambient temperature and humidity sensors.
  • Electrical Telemetry Acquisition: Precision voltage and current tracking for laboratory equipment testbenches.
  • AI Anomaly Detection: Machine learning classifier detecting thermal surges and current overdraw.
  • Digital Twin Telemetry: Live synchronized visual state mapping the laboratory in real-time.
  • Smart Alerts & Predictive Maintenance: Automated threshold alerts preventing equipment burnout.

AI Smart Attendance System

Computer Vision-Based Automated Attendance Logging with Cloud Synchronization

GitHub Repository
Current Milestone: Face Liveness & Anti-Spoofing Optimization
Core face recognition & Google Sheets sync pipeline completed; edge optimization underway.
75% Complete

An automated contactless attendance tracking system leveraging OpenCV and deep learning face recognition representations in Python and Flask. Designed to streamline academic and organizational attendance, the system captures real-time video feeds, runs anti-spoofing liveness checks, verifies identity against local SQLite biometric databases, and instantly pushes synced timestamped attendance logs directly to cloud Google Sheets spreadsheets. Full production release is coming soon!

Technical Highlights:

  • OpenCV Computer Vision: Multi-face detection and landmark tracking with high FPS throughput.
  • 128-d Feature Embeddings: Deep metric Euclidean distance calculation for robust identification.
  • Anti-Spoofing Heuristics: Texture analysis preventing static photograph replay bypasses.
  • SQLite Persistence: Secure local relational database caching timestamps and user metadata.
  • Google Sheets API Integration: Real-time asynchronous cloud synchronization for administrative review.
